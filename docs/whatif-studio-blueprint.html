The layer stack

One import direction, top to bottom. src/ never knows a browser or a web framework exists.

Hand-rolled CSS + SVG charts, no UI/chart library. Pages compose React Query calls into typed api/*.ts wrappers.
backend/app/

The actual math and I/O — model training, the What-If dependency-graph engine, config parsing. Independently testable.
